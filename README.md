# SecurePass 🔐

SecurePass is a Password Strength & Policy Validator built using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

## Features
- Password strength validation
- Score out of 10
- Show/Hide password
- Password policy validation
- Save validation results to MySQL
- Console-based password testing

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL

## Project Structure
```
SecurePass/
├── frontend/
├── backend/
└── consoleApp.js
```

## How to Run

### Backend
```
cd backend
npm install
node server.js
```

### Frontend
Open `frontend/index.html` using Live Server.

### Console Application
```
node consoleApp.js
```
